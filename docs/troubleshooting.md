# トラブルシューティングガイド

本ドキュメントでは、本システム（`splitstitch`）の実行時によく遭遇する問題、原因、および解決方法を記述します。

---

## 1. 環境と外部ツールに関する問題

### 1.1 `ffmpeg not found in PATH or ~/.local/bin`
- **現象**: 動画解析（`probe`）や分割（`split`）の実行時にエラーが発生する。
- **原因**: システムに FFmpeg または ffprobe がインストールされていないか、実行ファイルのディレクトリが環境変数 `PATH` に含まれていません。
- **対処法**:
  - Linux (Ubuntu): `sudo apt-get install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Windows: 公式サイト等から静的バイナリをダウンロードし、`bin` フォルダをシステムの環境変数 `PATH` に追加してください。
  - あるいは、ホームディレクトリの `~/.local/bin/ffmpeg` および `~/.local/bin/ffprobe` に直接バイナリを配置してください。

## 2. 動画分割（Split）に関する問題

### 2.1 `Frame count mismatch: got X, expected Y` (終了コード 5)
- **現象**: チャンク動画のエンコード後に検証エラーが発生し、処理が停止する。
- **原因**: 元動画のタイムスタンプが不規則（可変フレームレート: VFR）であるか、キーフレーム間隔が長すぎてシーク時に目的のフレームを正確にデコードできなかった可能性があります。
- **対処法**:
  - `splitstitch probe input.mp4` を実行し、`Rate Mode` が VFR になっていないか確認してください。
  - 元動画をあらかじめ固定フレームレート（CFR）に再エンコードするか、重なり秒数（`--overlap-sec`）を長めに設定（例: `1.5` 秒）して再試行してください。

### 2.2 `File size exceeds max limit` (容量超過)
- **現象**: 生成されたチャンクのファイルサイズがプラン上限（例: Free プランの 50 MB）を超えて停止する。
- **原因**: 映像の動きが非常に激しい、またはノイズが多く、CRF 18 でのエンコード時にビットレート上限に張り付いた結果、コンテナのヘッダー等のオーバーヘッドが見積もりを超過した可能性があります。
- **対処法**:
  - 画質プリセットを `--quality balanced`（CRF 20）または `--quality compact`（CRF 22）に変更して実行してください。
  - 解像度ポリシーを `--resolution 1080` に固定してください。

## 3. モーション結合（Stitch）に関する問題

### 3.1 `Found X motion files, but manifest specifies Y chunks` (ファイル照合エラー)
- **現象**: モーションフォルダを指定した際に、ファイル数の不一致で停止する。
- **原因**: QuickMagic からダウンロードしたファイルのうち、一部のチャンクのダウンロードが漏れているか、不要なファイルがフォルダ内に混入しています。
- **対処法**:
  - フォルダ内に `chunk_001of003.fbx` や `chunk_002of003.fbx` など、すべてのチャンク番号に対応するファイルが存在することを確認してください。
  - フォルダ内に対象セッション以外のファイルが存在する場合は、別の空フォルダに目的のファイルのみを移動して指定してください。

### 3.2 チャンクの接合境界で足滑りや位置飛び（テレポート）が発生する
- **現象**: 結合後のアニメーションで、チャンクが切り替わる瞬間にキャラクターが一瞬テレポートするか、足が滑る。
- **原因**:
  1. 重複区間（オーバーラップ）が短すぎて、同一フレームでの剛体アラインメントの推定精度が不足している。
  2. QuickMagic 側の姿勢推定が、チャンクの開始直後または終了直前で安定していない（エッジ効果）。
- **対処法**:
  - 分割時の重なり秒数を長め（`--overlap-sec 1.5` または `2.0`）に設定して動画を再分割してください。
  - 結合時のアラインメント設定が `--align yaw+xz`（既定）になっていることを確認してください。
  - ブレンド秒数を `--blend-sec 0.6` などに広げてみてください。

### 3.3 VMD 形式で結合した際に 60 fps / 120 fps が再現されない
- **現象**: 60 fps で時間軸拡張を行って QuickMagic から VMD を取得し結合したところ、完成した VMD が 30 fps になっている。
- **原因**:
  - **VMD フォーマットの規格上の制限**です。Vocaloid Motion Data (.vmd) は 30 fps の整数フレーム番号のみを扱う構造のため、60 fps をそのまま記録することができません。
- **対処法**:
  - 本システムでは 30 fps へ自動リサンプルして書き出します。60 fps や 120 fps の高精細なモーションデータを無損失で利用したい場合は、**FBX** または **BVH** 形式でエクスポート・結合してください。

### 3.4 複数人が映っている映像で骨格が破綻する
- **現象**: チャンク境界で別の人物の骨格データと入れ替わってしまう。
- **原因**:
  - 本システムは単一人物の連続テイクを前提としています。QuickMagic が複数人を検出し、チャンクごとに人物 ID の割り当て順序が入れ替わると接合が破綻します。
- **対処法**:
  - 映像内に他の人物が映り込まないようにトリミングするか、画角を調整した素材をご使用ください。
